# 商业提案写作手册（Proposal Playbook）

> 撰写商业提案、项目简报、合作请求时读取本文档。核心是两个工具：七步框架（完整提案）与一页六要素（一页简报）。

## 先分清两个概念

| | 提案书 Proposal | 企划书 Business Plan |
|---|---|---|
| 回答的问题 | 我们该做什么 | 究竟怎么做 |
| 使用场景 | 说服决策者批准一个行动 | 详细规划执行与财务 |
| 信息密度 | 一页/一屏讲清 | 多页详述 |

企业趋势正从"被动提案"（被要求才写）走向"主动提案"（发现问题主动提出）。主动提案是展示战略思维的最佳载体。

## 提案被采纳的公式

**被采纳 = 关系 + 内容 + 收益**

- **关系**：契合决策者的期望，站在对方视角写（对方的 KPI、对方的痛点、对方的语言）
- **内容**：结构清晰、论证严谨、证据可靠
- **收益**：明确"采纳后对方得到什么"，收益尽量可衡量

## 三种说服工具

1. **数据**：数字、统计、基准对比。必须标注可靠来源；无来源的数字是定时炸弹。
2. **案例**：同类组织/项目的成功先例，说明"别人这样做成了"。
3. **关键词**：决策者语境里的高频词（降本、合规、用户增长、ESG 评级）——用他们的词包装你的方案。

三种工具混用效果最好：数据给理性支撑，案例给信心，关键词给熟悉感。

## 七步框架（提案正文结构）

1. **分析现状**：我们身处什么局面（用 2–3 个关键事实）
2. **识别核心挑战**：不解决会怎样（制造紧迫感，但不夸大）
3. **定义核心策略**：我们的总体思路（一句话）
4. **设定目标受众**：这个方案服务谁（具体到群体画像）
5. **确立具体方法**：怎么做（方法要与挑战一一对应）
6. **确定执行计划**：时间表、里程碑、负责人
7. **明确预算与预期回报**：花多少钱、换来什么（回报尽量量化）

**对应关系自检**：挑战与方法之间必须一一对应——每一个挑战都有方法回应，每一个方法都指向某个挑战。悬空的方法（不解决任何挑战的花架子）和无解的挑战（提了但没回应）都要删。

## 起承转合四幕结构

东方叙事结构用在提案里天然顺畅：

- **起**：现状与背景（短，最多 15%）
- **承**：挑战与机会（为什么现在必须行动）
- **转**：方案核心（我们的方法与差异化）
- **合**：行动请求与预期成果（收束到一个明确的 CTA）

## 一页足矣（One Page Rule）

一页 A4 项目简报的标准：**潜在合作伙伴 1 分钟内看懂，15 秒内抓住核心**。它应该看起来像"提案的视觉摘要"，而不是"压缩版的完整报告"——区别在于留白、层级和聚焦，而不是字号。

### 一页简报必备六要素

1. **问题**：只聚焦一个中心问题（多问题 = 没重点）
2. **目标群体**：谁、在哪里、多少人
3. **核心解决方案**：一段话说清做法
4. **3 项关键活动**：1 个核心 + 2 个支持性，不要罗列 8 项
5. **1–2 项可衡量结果**：用数字表达的成功标准
6. **合作请求**：具体到人、财、物

### 五条好提案标准

1. 问题清晰（读者看完能复述）
2. 解决方案实用（不做梦）
3. 本地情境贴合（不生搬硬套）
4. 结果可衡量（"学生营养知识提升 30%"而非"提升意识"）
5. 有一句易记的话 + 清晰的视觉结构

### 五类常见问题（写作时规避，审查时排查）

1. 信息过多（什么都想说 = 什么都没说）
2. 活动无优先级（3 项以上并列 = 无重点）
3. 数据无支撑（编造或来源不明）
4. 规模与预算不一致（声称覆盖 10 万人，预算 1 万元）
5. 合作请求不清晰（"寻求支持"不是请求）

### 试点规模建议

首次试点要小而具体，证明可行后再扩展。参考量级：**一个村庄、1–2 所学校、100–300 名学生、六个月**。小规模不是格局小，是让决策者觉得"这事靠谱、可控、可复制"。

### 措辞的可信度细节

- 避免绝对化表述："Eliminate poverty" → "reduce poverty by 20%"。绝对化承诺等于给质疑者递刀。
- 合作请求具体化示例：❌ "希望得到各方支持" → ✅ "寻求一所合作学校、一个营养专家团队和 10 万元人民币，开展六个月试点"。
- 数据必须有可靠来源并标注。

## 工作流

1. 确认提案类型：完整提案（七步框架）还是一页简报（六要素）？
2. 按 O1–O5 分析决策者读者，列出对方最关心的 2–3 个问题
3. 用七步框架或六要素搭骨架，执行"挑战与方法对应"自检
4. 起草，执行一页/一屏原则
5. 用"五条好提案标准"和"五类常见问题"双向检查
6. 四层修订后交付
