# 利益相关者写作工具（Stakeholder Canvas）

> 涉及多群体沟通、危机声明、敏感议题时读取本文档。四个工具按顺序用：先分层（PIM / 显著性模型），再逐群体写（写作画布），最后调语气（四个杠杆）。

## 为什么需要利益相关者分析

一份文本的读者从来不止一个群体，而不同群体的利害关系不同——同一份"通用公告"对债权人是信息不足，对购房者是避重就轻。写作前先回答：**谁读？他/他们利害是什么？读完要他们做什么？**

## 工具一：权力-利益矩阵（Power-Interest Matrix, PIM）

按"权力（影响组织的能力）× 利益（受此事影响的程度）"把群体放进四格：

| | 高利益 | 低利益 |
|---|---|---|
| **高权力** | 密切管理 Manage closely：细节、时间表、参与决策的机会 | 保持满意 Keep satisfied：简洁、尊重、确认其立场 |
| **低权力** | 充分告知 Keep informed：主动推送进展，不等追问 | 最低关注 Monitor：公开信息即可 |

## 工具二：利益相关者显著性模型（Salience Model）

紧急公告中实际被服务的群体往往由三个属性决定：**权力 Power、正当性 Legitimacy、紧迫性 Urgency**。三个属性都具备的群体（Definitive 群体）会被优先服务——危机公告中这通常是投资者与债权人（信息披露义务 + 市场压力）。

**核心洞察（高杠杆房企债务危机的公开声明中反复出现）**：公开声明说"服务所有利益相关者"（all stakeholders），实际指的常是财务与法律群体。购房者、员工被修辞式纳入（提及"保交楼""员工安置"），却欠实质性沟通。写作启示：

1. 危机声明天然偏向 Definitive 群体——这是制度压力使然，但不是沟通充分的证明。
2. "all stakeholders"是修辞统称，不等于沟通覆盖。判断谁被真正服务，看**信息细节给了谁**。
3. 正确做法是**分众沟通**：高权力高利益群体给重组细节与时间表；低权力高利益群体（购房人、员工）给复工与交付安排、工资与岗位说明——即使他们不施压。

## 工具三：利益相关者写作画布（Stakeholder Writing Canvas）

为**每个关键群体**单独走一遍这张画布，产出定制段落：

| 步骤 | 问题 | 示例（数据泄露危机中的客户） |
|---|---|---|
| **Target Stakeholder** | 这一段写给谁？ | 受影响的个人客户 |
| **Stake** | 他们在此事中的利害是什么？ | 个人信息安全、财产风险 |
| **Objective** | 读完要他们做什么/感受到什么？ | 知道风险范围，完成密码修改 |
| **Message Choices** | 内容选什么、顺序怎么排、语气多重？ | 先说影响范围与自查方法，共情语气，不淡化 |
| **Call to Action** | 具体的下一步是什么？ | "请在 7 日内通过 App 修改密码并开启双重验证" |

## 工具四：四个写作杠杆

针对不同群体调整文本的四个抓手：

1. **内容**：写什么、不写什么（给债权人的重组条款不放进客户公告）
2. **顺序**：先结果后背景，还是先背景后结果（坏消息永远先说影响）
3. **语气**：正式程度与共情程度（对投资者冷静专业，对受影响者先共情）
4. **行动号召**：每类读者一个明确的 CTA（不要用"如有疑问请随时联系"敷衍）

## 危机写作特别规则

1. **坦诚用词**：是"泄露"就说泄露，不用"安全事件"淡化；是"道歉"就道歉，不用"深表遗憾"回避责任。
2. **信息顺序**：事实与影响 → 已采取的行动 → 读者可做的事 → 承诺后续沟通时间点 → （最后才）原因说明。不找借口、不甩锅、不指责用户。
3. **统一口径 + 内部优先**：对外声明发布前先给内部员工版本（员工从媒体得知公司危机 = 第二次危机）。
4. **次生受众假设**：写每一段时假设它会被所有群体截图传播。对债权人说的话会被购房者读到——如果那段话会让购房者愤怒，改写它或补写面向购房者的段落。
5. **不承诺做不到的事**：恢复时间、赔偿方案只写已确认的；未确认的写"我们将在 X 前给出明确答复"。
6. **模拟情境标注**：练习或提案中的危机场景必须明确标注为模拟，不得虚构真实组织的危机数据。

## 多受众文本的自检清单

- [ ] 每个关键群体都走过了写作画布
- [ ] 每类读者都有独立的、具体的 CTA
- [ ] 没有"all stakeholders"式偷懒（修辞覆盖 ≠ 沟通覆盖）
- [ ] 坏消息受众（低权力高利益群体）获得了实质性信息
- [ ] 各群体版本口径一致，无矛盾承诺
- [ ] 每段都能通过"被其他群体读到"的假设检验
